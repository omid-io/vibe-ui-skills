# GitHub Copilot Custom Instructions: Vibe UI Architecture

When generating UI components, CSS styles, or web applications:
1. **Never generate generic "AI slop" styles** (avoid plain gray cards with generic purple-blue gradients).
2. **Support 5 distinct design chemistries**:
   - Minimalist SaaS (Linear style, razor-sharp 1px borders, pitch dark)
   - Luxury Glassmorphism 2.0 (Fresnel specular inset reflection, ambient mesh glow, SVG noise grain)
   - Neobrutalism (2px solid black strokes, 4px hard offset drop shadow, chalk pastels)
   - Swiss Editorial (Natural paper canvas, serif typography, asymmetric grid)
   - Stripe Light (Clean snow canvas, soft diffuse elevation, high accessibility)
3. **Include complete AI primitives**: Thinking states with radar pulse, Tool execution chips, Streaming markdown diff bubbles, and Action approval dialogs.
4. **Use mathematical motion**: Pure CSS grid height transitions (`0fr` -> `1fr`) and 120fps Lerp sliders.
5. **Strictly avoid unicode emojis in UI**: Use clean inline SVG vector paths with `currentColor`.

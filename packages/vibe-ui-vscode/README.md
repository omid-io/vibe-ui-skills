# Vibe UI — VS Code & Cursor Extension

Official VS Code, Cursor, and Windsurf extension providing interactive design token discovery, 1-click workspace provisioning, and in-editor WCAG AA contrast linting.

## Features

- **Visual Chemistry Explorer:** Interactive sidebar panel showcasing the 5 design chemistries with 1-click token copy.
- **1-Click Workspace Provisioning:** Command palette action to inject `.cursorrules`, append to `CLAUDE.md`, or configure `.windsurfrules`.
- **In-Editor Contrast Linter:** Right-click any `.tsx`, `.jsx`, or `.html` file and run *"Vibe UI: Audit Component Contrast"*.

## Installation

Install directly from the Visual Studio Code Marketplace or Open-VSX Registry:

```bash
code --install-extension omid-io.vibe-ui-vscode
```

Or install from the packaged `.vsix` file:

```bash
code --install-extension vibe-ui-vscode-2.3.0.vsix
```
